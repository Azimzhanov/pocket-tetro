# Pocket Tetro v0.5 — Casual Balance

## Запуск
Распакуйте ZIP и откройте `index.html` через Live Server в VS Code либо в современном браузере. Сеть для офлайн-режимов не требуется. Старые сохранения v0.4 сохраняются: используется тот же ключ localStorage.

## Изменения
- **Обычный режим 8×18:** 6 фигур разного размера: Уголок (3), Линия (3), Квадрат (4), Ступень (5), Короткий крюк (4), Карман (5). Классические BAR, TEE, ELBOW, STEP удалены из обычного набора. Продвинутый 9×22 сохраняет прежние 8 фигур.
- **Доступный Pulse:** обычный — 4 заряда, продвинутый — 5. Каждая очищенная линия даёт минимум один заряд; начиная с Combo ×3 обычный режим даёт ещё один заряд при успешной очистке. Бонус за полный Pulse: +350 в обычном, +500 в продвинутом. Бонусы за отдельные заряды сохранены.
- **Доступные Combo:** в обычном серия прерывается после 3 подряд фигур без очистки, в продвинутом после 2. Цветовые стадии Flame Chain прежние.
- **Фиксация:** 350 мс в обычном, 300 мс в продвинутом. Автоматическое ускорение прежнее.
- **Tetro Lab:** выбор фигур обычного режима обновлён, включая изображения; испытания используют новую трёхклеточную линию.
- Обновлены текст помощи и геометрический вычислитель, добавлена короткая подсветка заполнения Pulse.

## Сохранено из v0.4
Лобби, профиль и локальные рекорды, рамки и достижения, фото, почта, магазин, VIP-макет, настройки, русский/английский, управление на телефоне, повторы с перемоткой и экспортом, перенос момента в Tetro Lab. Онлайн-сервисы, реальные платежи и рассылка сообщений **не подключены**.

## Ограничения
Это изменение баланса основано на свойствах фигур, а не на подтверждённых испытаниях с реальными игроками. Сложность и начисление очков потребуется уточнять после тестов.
